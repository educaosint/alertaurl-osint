# Seguridad

No publiques vulnerabilidades, credenciales ni datos de víctimas en una incidencia pública.

Para comunicar un problema de seguridad de forma responsable, contacta primero a Educa OSINT mediante su cuenta oficial: https://www.instagram.com/educaosint/

Incluye una descripción breve, pasos de reproducción seguros y el impacto observado. No pruebes técnicas destructivas contra el servicio o sitios de terceros.
